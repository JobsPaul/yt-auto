# YT Auto: ดู YouTube บน Android Auto (ติดตั้งเอง ใช้ส่วนตัว)

แอปนี้ไม่ได้อยู่บน Google Play ต้องติดตั้ง APK เอง วิดีโอจะ**เล่นได้เฉพาะตอนรถจอดนิ่ง**

## หลักการทำงาน
- ประกาศตัวเป็นแอป "นำทาง" เพื่อให้ Android Auto ส่ง Surface สำหรับวาดภาพบนจอรถมาให้
- Surface → `VirtualDisplay` → `Presentation` → `WebView` ที่เปิด `m.youtube.com`
- การแตะและปัดบนจอรถจะส่งต่อเข้า WebView (การปัดต้องกดปุ่ม Pan ก่อน)
- ปุ่มบนจอรถ: **ค้นหา** (ใช้คีย์บอร์ดของรถ) / **เล่น/หยุด** / **ย้อน** / **หน้าแรก**
- ระบบล็อก (`ParkingGuard`): อ่านความเร็วจากรถก่อน ถ้าไม่ได้จะใช้ GPS ของมือถือ
  ถ้าความเร็วเกิน ~1.8 กม./ชม. หรือไม่รู้ความเร็ว จะปิดจอดำและหยุดวิดีโอทันที

## Build APK
**วิธีที่ 1: Android Studio**: เปิดโฟลเดอร์นี้ แล้วกด Build > Build APK(s)
หรือรันใน terminal: `./gradlew assembleNavDebug`
ไฟล์ที่ได้อยู่ที่ `app/build/outputs/apk/nav/debug/app-nav-debug.apk`

**วิธีที่ 2: GitHub Actions**: push ขึ้น GitHub repo แล้ว workflow `Build APK` จะ build ให้
ดาวน์โหลดได้จากหน้า Actions > run ล่าสุด > Artifacts

## ติดตั้งและเปิดใช้
1. ติดตั้ง APK บนมือถือ (ต้องอนุญาต "ติดตั้งแอปที่ไม่รู้จัก")
2. เปิดแอป YT Auto บนมือถือ แล้วกดอนุญาตตำแหน่ง
3. Android Auto > แตะ "เวอร์ชัน" 10 ครั้ง > ⋮ > การตั้งค่าสำหรับนักพัฒนาซอฟต์แวร์ > เปิด **Unknown sources**
4. เชื่อมต่อรถ แอปจะอยู่ในหน้ารวมแอป (ถ้าไม่เห็น ให้เพิ่มที่ "ปรับแต่ง Launcher")

ทดสอบโดยไม่ต้องใช้รถ: ใช้ Desktop Head Unit (DHU) จาก Android SDK (SDK Manager > Android Auto Desktop Head Unit)

## ข้อจำกัด
- Google อัปเดต Android Auto แล้วอาจทำให้แอปที่ติดตั้งเองใช้ไม่ได้
- รถบางคันไม่ส่งความเร็วมา ระบบจะใช้ GPS แทน ถ้าจอดในที่ไม่มีสัญญาณ GPS วิดีโอจะถูกล็อกไว้
- ต้องพิมพ์ผ่านปุ่ม "ค้นหา" เท่านั้น การแตะช่องพิมพ์บนหน้าเว็บจะไม่มีคีย์บอร์ดขึ้น
